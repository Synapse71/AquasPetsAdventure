# Idle Expedition Demo

异步宠物冒险与撤离玩法 Demo。已接入 macOS Electron 桌宠外壳、透明动画、拖拽定位和五个菜单入口；面板内部仍在从系统 Demo 迁移到定稿原型。

平时只显示宠物；点击展开状态、库存、行动、图鉴和设置五个入口，任务在行动面板内。完整实现状态见 [桌宠客户端实现记录](docs/desktop-client-implementation.md)。

## 运行

macOS 桌面版（本地构建，不依赖开发服务器）：

```bash
npm install
npm run start:desktop
```

桌面版热更新开发：`npm run dev:desktop`（同时启动 5173 端口的 Vite，不能与另一个同端口服务同时启动）。

桌宠采用单实例运行；切换开发/构建模式前请先退出当前桌宠，隐藏不等于退出。

浏览器 Demo 和策划后台保持原入口：

```bash
npm install
npm run dev
```

桌宠 Demo：`http://127.0.0.1:5173/`

本地策划配置台：`http://127.0.0.1:5173/?config=1`

配置台使用浏览器本地存储保存草稿和已应用配置，不需要数据库或账号。支持分类管理、表单与 raw JSON 双模式编辑、地图节点与路线表单、实时有向拓扑图、掉落表、按稀有度筛选物品、新增、复制、删除、引用校验、地图无环校验以及整包 JSON 导入导出。应用新配置时会重置 Demo 存档。

注意：配置台一旦保存过，浏览器本地存储里的那份配置就会盖过代码内置目录。代码改动看不到时，点「恢复默认」即可回到内置版本。

测试与生产构建：

```bash
npm test
npm run build
npm run test:desktop
```

`test:desktop` 使用临时 Electron 存档进行真实窗口测试，截图保存在 `artifacts/desktop-smoke/`。不读写玩家现有游戏存档。

浏览器与 Electron 的存档独立；桌面开发模式（HTTP）与本地构建模式（file）也使用不同的浏览器存储来源。当前不会自动迁移已有浏览器存档。

## 当前闭环

```text
自由配队
→ 固定地图与现实时间等待
→ 有限随机事件（够不到的事件不参与抽取，节点会列出所需门槛）
→ 风险选择（不达标的选项置灰；次要属性条件随三档情报逐步揭示）
→ 路线或立即撤离
→ 撤离整理（负重 / 背包格子 / 仓库格子，可丢弃或就地出售）
→ 战利品直接入库，结算节点经验与战利品经验
→ 出售、提交任务或喂给宠物提升次要属性
→ 升级加点、扩充仓库与账号成长
→ 伤势按真实时间恢复，也可花钱立刻治好
→ 再次冒险
```

**宠物有两层属性。** 三项主属性（体能 / 感知 / 技巧）用属性点提升，各自对应一条加点当场可见的机制：负重上限、地图与事件情报等级、背包格子上限。四项次要属性（口才 / 学识 / 勇气 / 狡黠）是硬门槛，不消耗属性点，只能靠专用道具提升；不达标时内容置灰而不是隐藏。第一档只在不达标时提示属性不足，第二档进一步显示成功门槛，第三档始终显示成功与大成功门槛。

物品分六档稀有度（白常见 / 绿罕见 / 蓝稀有 / 紫史诗 / 黄传说 / 红神话）。地图、事件、物品的具体数量仍在调整，以配置台显示为准。

工具不是独立分类，就是带 `tool` 标签的普通物品；旧的独立工具系统已从代码中移除。

### 仓库素材范围与凭据安全

仓库只提交游戏构建使用的最终素材：`public/pet-sprites/`、`public/icons/`，以及 `.gitignore` 白名单中的物品图标、UI 图标、骰面、宝箱动画和两张地图图。原视频、逐帧原图、候选稿、源图和动画素材预览包仅保留在美术工作目录，不进入 Git 历史。

克隆仓库后可直接运行 `npm ci`、`npm test` 和 `npm run build`，无需重新生成美术。`npm run assets:pet` 及 Python 美术管线/原图测试需要另外准备本地原素材；部分历史原型的素材预览也依赖这些本地文件。

本地 AI 工具目录、环境配置、私钥、服务调用结果/状态记录、缓存和测试截图均不提交。美术工具通过本机 `atlas-skillhub` 调用 liclick，仓库不保存其账号或密钥；不要把凭据写入代码、文档或素材元数据。

核心规则不得写入 React 组件。宠物、地图、事件和物品等策划内容统一在配置台维护，确认后用导出的完整 JSON 覆盖 `src/domain/catalog.bundled.json`；`src/domain/catalog.ts` 只负责加载它。新增规则时修改 `src/domain/engine.ts` 并补充测试。
