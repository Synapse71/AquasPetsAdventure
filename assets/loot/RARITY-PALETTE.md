# 战利品图标 · 美术规范

## 图标风格：B 粗描边扁平（已定稿 2026-08-11）

- 每件物品外围一圈**粗细均匀的深色描边**，描边不用纯黑，用该物体固有色加深两度的同色系深色。
- 内部只做**两层平涂色块**（受光面 / 背光面），无渐变、无细腻质感，最多补一两笔白色斜向高光条。
- 形状高度概括，只保留最能认出这件东西的特征。
- 配色低饱和、柔和，明度对比清楚。
- 略微俯视的四分之三视角，光源统一来自左上方。
- 物体悬空，不画地面 / 投影 / 托盘 / 底座。
- 定稿提示词见 `style-explore/loot_style_B.json`。

## 稀有度物品格底色（v2 · 当前方案）

边框**六档统一**，不参与档位区分；区分完全交给填充色，饱和度大幅拉开。

**唯一硬约束：六档填充明度必须保持中高、不能用深色。**
B 风格的图标自带深棕色描边，靠描边和底色的明暗差撑出边界。
一旦高档位用饱和深色（深紫、深红），深描边就会糊进底色，
图标反而比 common 更难认——稀有度越高越看不清，是反的。

| 档位 | 中文 | 色名 | 格子填充 | 选色理由 |
|---|---|---|---|---|
| common | 常见 | 白 | `#E3E3E3` | 中性灰，无色相倾向，取自风格测试原图背景 |
| uncommon | 罕见 | 绿 | `#A8DC82` | 草绿而非荧光绿，避免和"可用/成功"的系统绿混淆 |
| rare | 稀有 | 蓝 | `#74B9F0` | 天蓝 |
| epic | 史诗 | 紫 | `#B98BEE` | 紫偏红，和蓝档在色相上拉开足够距离 |
| legendary | 传说 | 黄 | `#F3C63C` | 金黄偏橙，不用纯柠檬黄（纯黄刺眼且显廉价） |
| mythic | 神话 | 红 | `#EF6B55` | 朱红偏橙，避开正红——正红在 UI 里默认读作报错 |

**边框、圆角、留白等格子样式由背包系统 UI 决定，不属于美术素材范围。**
上表只定填充色。图标在格内留白建议 12%~14%，仅供参考。

- `style-explore/_v2稀有度底色-大图.png`（底色本身）
- `style-explore/_v3图标×稀有度底色-大图.png`（真实图标 × 底色）
- `style-explore/_v3图标×稀有度底色-小图64px.png`

## 素材交付形态

**底色绑定稀有度，不绑定物品。** 策划改一件物品的稀有度时不需要重出美术。
因此合格的图标素材必须是**透明背景 PNG**，底色由 UI 在运行时铺。

出图管线：GPT Image 2 出 2×2 四宫格（浅灰底）→ 按象限切开 → 抠图 → 单件透明 PNG。

抠图方法（脚本 `tools/loot_matte.py`）：
先从四角 flood fill 吃掉外部背景，再判定"被物体包围的区域"是真孔洞还是浅色高光。
**这两者在颜色上会重叠**（银手镯高光明度 238，背景 233，只差 5），必须量化区分。

**主判据：区域中位明度与背景的差 Δ。** 实测区分度最大：

| | Δ明度 | 边界深色占比 |
|---|---|---|
| 钛合金戒指中孔 | −0.3 | 0.22 |
| 玩具无人机保护圈孔 | −0.7 ~ +1.3 | 0.20 ~ 0.28 |
| 银手镯高光 | +4.7 / +4.3 / −3.7 | 0.11 |

真孔洞就是"透过物体看到的背景"，Δ 必然趋近 0（容差 2）；浅色高光是画上去的，Δ 在 ±3.7 以上。
**边界深色占比只能当兜底（阈值 0.15），绝不能当主判据**——真孔洞 0.20~0.28、高光 0.11，
两者挨得太近；早期把阈值设在 0.25，正好切在玩具无人机那堆孔洞中间，
导致四个保护圈有的抠了有的没抠，钛合金戒指的中孔（0.22）也被误留。

**更早的一版（按颜色容差撒种子 + flood fill 扩散）完全是错的**，它把物体内部的浅色高光
当成孔洞整片挖穿，75 件里 34 件中招，最严重的碎瓷片找回 +79.9% 像素、灯泡 +52.8%、
塑料杯子 +52.6%、空塑料瓶 +46.0%、银手镯 +42.2%。
对比图 `style-explore/_抠图修复对比.png`（品红底，上排旧下排新）。

**回归检验靠不透明像素数**：同一件重切前后差异 >0.5% 就要人工确认，
正数通常是找回高光，负数是补上了漏抠的孔洞。

**中灰背景方案已验证并否决。** 曾设想把生成背景改成 `#9A9A9A` 让高光和背景在明度上彻底分开，
用同一批 epic 物品在浅灰底和中灰底各出一张直接对比（`style-explore/epic-e1_light.png`
与 `epic-e1_grey.png`），结果画面确实变了：钻石耳钉的刻面细节被简化、手袋锁扣从搭扣变成挂锁、
耳钉描边明度从 60 掉到 36。而它要解决的抠图歧义已被 Δ明度判据解决，收益归零、风险不可控，
因此**继续用浅灰底**。
（注：跨物品比较描边色是无意义的——规范本就要求描边用固有色加深两度的同色系，
小提琴是暖棕描边、镜头是中性黑描边，只有同一物品跨背景对比才说明问题。）

### 强制验收流程

`python3 tools/loot_qa_sheets.py` —— 每次新增或重出图标后必跑。它做两件事：
1. 自动检测白色模切边（见下）；
2. 把所有图标铺在**品红底**上，9 个一组输出 `style-explore/_品红验收-NN.png`。

**必须在品红底上验收，不能在浅灰底或成品稀有度底色上验收。**
抠图挖穿的洞在那些底色上和物体自身的浅色高光长得一模一样，肉眼分辨不出来。

注意程序化的孔洞检测（按边界深色占比判可疑）会大量误报——齿轮/轴承/胶带的心孔、
剪刀指环、弹簧圈间、项链圈内这些合法孔洞的边界一半是描边一半是物体色块，占比只有 0.25~0.4。
孔洞这一关只能靠品红印样肉眼过。

## 带字物品的写法

全局负面提示词把「文字、字母、汉字、数字」整条封死（防键帽、电池、卷尺、罐头标签冒字）。
个别物品确实需要带字符时（如键帽上的 M），**只解禁那一个具体字符，其余全部保留封锁**，
并在正文里写死"只允许出现这一个大写英文字母 M，不要出现任何其他字母、汉字、数字或符号"。
不要图省事把整条文字负面删掉。

## "失去光泽 / 破损"类物品的写法

cracked-core 第一版把"黯淡无光"理解成把颜色洗淡，结果青绿松石变成了青瓷灰绿，
偏离参考图。正确写法是：**固有色保持饱和，黯淡靠压明度和砍高光实现，而不是把颜色洗淡**。

## 出图时的复发缺陷

**模型会在深色描边外面再套一圈白色模切边。** 来源是风格描述里那句"整体像一张剪下来的贴纸"，
模型把比喻当成了工艺要求。**按整张四宫格随机发生，与画的是不是同一件物品无关**
（巧克力那次是四个变体，rare-r1 那次是四件不同物品）。
防护条款已永久写进基础提示词 `style-explore/loot_style_B.json`，正文加"物体外围只有一圈深色描边，
之外绝对不能再套一圈白色或浅色轮廓边"，负面加 白色描边 / 贴纸白边 / 模切白边 / 双层描边。

**这个缺陷在浅灰底和成品底色上都极难用肉眼发现**，必须靠指标：
量 alpha 边缘往内 6px 环带里近白像素（明度 >235）的占比，正常图标 <10%，中招的是 100%。
已集成进 `tools/loot_qa_sheets.py`，每次跑验收自动检。
rare-r1 那张（智能手表/游戏手柄/平板电脑/便携音箱）已重出修复。

**深色/破烂档的金属零件会被画成金色。** 齿轮在批量出图时又一次出成黄铜金色
（当初否掉厚涂风格 A 的正是这条），说明这不是某个风格的毛病而是模型的普遍倾向：
"金属零件"容易被理解成"贵重零件"。已换回灰色版。
后续出任何金属类 common 物品，验收时必须专门检查有没有变金。

## 已知的弱配对

`#E3E3E3`（常见灰）配**浅色/半透明物品**时对比最弱。实测各图标不透明像素的平均明度
与灰底的差值，最接近背景的几件：纸张 −21（75% 的像素落在灰底 ±25 明度内）、
塑料杯子 −41（52%）、玻璃碎片 −45（58%）、灯泡 −59（42%）。
这几件仍然可读——靠的是深描边，描边本身离背景很远——但填充色确实糊进背景。
（注：其中塑料杯子、灯泡、空塑料瓶当时还同时被旧抠图挖穿了大量像素，观感更差，那个问题已单独修复。）
若要改善，把常见档填充压到 `#D6D6D6` 左右即可，代价是整体更灰。

`#74B9F0`（稀有蓝）配**蓝色物品**时同理，物品固有色和底色同色相。
若后续大量蓝色物品落进稀有档，把该档填充往青绿方向偏一点即可解决。

**细长构件的判断必须实测，不能靠印象。**
在接触印样里扫一眼容易把"比别的图标细"误判成"会断"。
正确做法：量出该构件在原图中的最细宽度，乘以缩放系数（`64 × 0.78 / 原图长边`），
得到它在 64px 下的实际像素宽度，再单独渲染 64 / 48 / 32 三档看。

已实测：台灯支架原图最细 60px，缩放系数 0.060 → 64px 下为 3.6px，
64px 与 48px 下连续清晰，32px 才开始发虚，不需要返工。
验证图 `style-explore/_台灯尺寸验证.png`。

外接框填充率（uncommon 最低的是专业钓竿 25%、雨伞 30%）只反映"整体胖瘦"，
不反映"局部粗细"，两个指标不能互相替代，也都不能替代实测。
