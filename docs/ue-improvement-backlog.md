# UE 与体验改进清单

记录日期：2026-09-10。

本清单记录玩家试玩后提出的后续改进需求，包含 UE、美术表现与数值体验。勾选表示已完成；序号仅用于引用，不代表优先级。

- [ ] **UE-01 · 丰富待机与行进动画**
  当前待机动画种类太少，探索行进过程中的动画变化也不足，需要增加动作丰富度，减少长时间观看的重复感。

- [x] **UE-02 · 调整宠物与气泡按钮的尺寸比例**
  2026-09-14 完成：本体最小尺寸 130px，最小气泡 16px，悬停显示功能名称；缩放期间锁定面板位置，松开后重新定位。布局单测与 Electron 真实鼠标拖动烟测通过，详见 [尺寸实现记录](pet-size-and-bubbles.md)。

- [x] **UE-03 · 支持拖拽至紧贴屏幕边缘**
  2026-09-14 按用户本次验收确认标记完成；本轮未另行修改贴边定位逻辑。

- [x] **UE-04 · 不可堆叠物品隐藏数量角标**
  2026-09-14 完成：库存面板的仓库和冒险背包按 `itemStackSize > 1` 显示角标，不可堆叠物品隐藏；可堆叠物品保留原有数量显示。探险格子原有的数量大于 1 才显示角标规则无需改动。详情、提示中的数量及实际堆叠、出售、丢弃规则不变。Electron 库存烟测验证仓库、背包角标与多件不可堆叠物品仍分格展示，并通过原有操作回归；全量 212 项单测与构建通过。

- [ ] **UE-05 · 调整第二张地图的探险时间与掉落价值**
  当前第二张地图探险时间太短，掉落物品价值太低。需要一起评估行进时长与掉落配置；具体目标时长、物品池和概率尚未确定。

- [ ] **UE-06 · 简化多个功能面板之间的切换**
  当前切换面板需要反复点击咕嘎，再点击对应气泡，操作繁琐。需要提供更便捷的面板切换方式，具体交互方案待设计。

- [ ] **UE-07 · 探险默认选中最新解锁地图**
  进入探险选图阶段时，默认选中最新解锁的地图，减少重复切换地图的操作。

- [ ] **UE-08 · 考虑不探险时做一个简单挂机活动缓慢获取战利品和成长经验**
  比如钓鱼。

- [ ] **UE-09 · 扩建仓储任务需要的材料掉落概率太低**
  在前几个节点增加常见材料的掉落概率。

- [ ] **UE-10 · 需要更多互动动画**
  多一些交互，点咕嘎可以给不同动画反馈，甚至点击不同位置反馈动画不同。

- [ ] **UE-11 · 开箱动画优化**
  现在的开箱动画没有期待值跟惊喜感，只适合用来做普通物品的开箱动画。不同稀有度的物品的开箱动画要做分别，从光芒颜色，到宝箱质感，再到开箱动画，都要有梯度的提升。

- [ ] **UE-12 · 开机自启动开关**
  实装开启自启动功能。
