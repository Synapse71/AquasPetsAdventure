# UE 与体验改进清单

记录日期：2026-09-10。

本清单记录玩家试玩后提出的后续改进需求，包含 UE、美术表现与数值体验。以下均为待处理项，不代表已经实现；序号仅用于引用，不代表优先级。本次只记录需求，不调整代码或配置。

- [ ] **UE-01 · 丰富待机与行进动画**
  当前待机动画种类太少，探索行进过程中的动画变化也不足，需要增加动作丰富度，减少长时间观看的重复感。

- [ ] **UE-02 · 调整宠物与气泡按钮的尺寸比例**
  咕嘎本体太大，气泡按钮太小。后续调整两者的尺寸与比例；具体尺寸待确认。

- [ ] **UE-03 · 支持拖拽至紧贴屏幕边缘**
  当前无法把咕嘎拖到紧贴屏幕的位置，需要检查拖拽边界与透明窗口留白，改善贴边定位体验。

- [ ] **UE-04 · 不可堆叠物品隐藏数量角标**
  不可堆叠的物品不应在物品图标右下角显示数量。此项调整展示规则，不改变物品实际数量或堆叠规则。

- [ ] **UE-05 · 调整第二张地图的探险时间与掉落价值**
  当前第二张地图探险时间太短，掉落物品价值太低。需要一起评估行进时长与掉落配置；具体目标时长、物品池和概率尚未确定。

- [ ] **UE-06 · 简化多个功能面板之间的切换**
  当前切换面板需要反复点击咕嘎，再点击对应气泡，操作繁琐。需要提供更便捷的面板切换方式，具体交互方案待设计。

- [ ] **UE-07 · 探险默认选中最新解锁地图**
  进入探险选图阶段时，默认选中最新解锁的地图，减少重复切换地图的操作。
