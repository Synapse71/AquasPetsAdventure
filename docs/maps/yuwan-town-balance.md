# 榆湾旧镇：掉落、路线与事件配表

本轮为现有拓扑填充内容，不修改节点、连线和布局。数据源为 `src/domain/catalog.bundled.json`，所有参数均可在策划配置台调整。

## 收益锚点与口径

- 用户锚点：完整探索金币 1000±100/小时、经验 40±5/小时；路段 45～75 分钟，大多数为 60 分钟。
- 32 条完整路线等概率，所有门槛满足、成功撤离、容量足够且全部带回；含入口固定 15 秒，不含玩家操作等待。
- 不计随机事件、任务和首次撤离奖励。经验是每只参战宠物所得，不除以队伍人数。
- 第三图平均 356.1875 分钟，5945.3972 金币、228.7587 经验，即 1001.5058 金币/小时、38.5345 经验/小时。
- 第一图排除渔具后为 634.7528 金币/小时、22.1737 经验/小时；第二图为 944.8054 金币/小时、28.8144 经验/小时。去掉低价渔具改变了池内均价，因此金币收益上升。
- 中途撤离的 8 条路径等概率：平均 179 分钟，2350.6125 金币、114.0508 经验。金币效率约 787.91/小时；该提前退出策略不作为完整通关收益锚点。
- 单节点期望价值：终点 > 中途撤离点 > 普通节点；实际单次随机结果不保证这一排序。
- 完整路线平均 24 件战利品；实际负重不足、丢弃、溃败会降低带回收益。事件收益取决于队伍和选项，另计。

## 事件与首撤

各小池内沿用现有等概率事件抽取：

| 节点 | 事件池内容 |
| --- | --- |
| 藤蔓庭院 | 灌木中的求救声／高处的包裹 |
| 旧邮局 | 拦路的蟊贼／暗藏机关的路障 |
| 社区活动室 | 上锁的工具箱／摇摇欲坠的杂物堆 |
| 钟表照相馆 | 无人认领的旅行包／临时交换请求 |
| 旧书店 | 被风吹散的纸页 |
| 镇立学校 | 正在坍塌的旧通道 |
| 观星小楼 | 延伸远处的奇怪脚印 |
| 山坡宅邸 | 固定 `doro-encounter`，无随机池 |

7 个随机节点加 1 个固定事件节点，占 17 个非入口节点的 47%。撤离点和终点无事件。Doro 未获得时固定相遇，交付 orange×1 后立即完成招募；获得后不再触发。节点先处理掉落，再处理事件。

所有现有事件奖励中的渔具均排除：“围拢的野犬群”两个选项的大成功额外奖励由专业钓竿×1 改为保温杯×1。

- 河港转运站首次成功撤离：破损核心（cracked-core）×1。
- 北口客运站首次成功撤离：伊卡洛斯量产机模型（icarus-mech-model）×1。
- 两处独立记录，均不进入普通掉落池。

## 游戏地图视窗

游戏地图使用固定 16:9 视窗，各地图自身比例与节点坐标不变；较高或较宽的地图在视窗内拖拽平移，不显示滚动条。键盘聚焦视窗后可用方向键平移。切换地图不改变翻页按钮的位置；选入口时定位到所选入口（未选时定位首个入口），探险中优先定位当前节点。拖拽超过阈值后不会误触入口选择。

中途撤离点使用出口箭头图标，终点使用旗帜，地图下方提供文字图例，无需额外美术资源。

## 后台读取与配置覆盖

没有本地覆盖时，后台和游戏直接读取新内置数据。已有旧草稿/已发布本地配置时，后台会提示“代码内置目录已更新”；确认本地改动已备份后，点击“用内置覆盖”，同时清除旧的发布覆盖层。不会静默覆盖用户的草稿或重置游戏存档。

回归测试：`src/domain/yuwanBalance.test.ts`。原拓扑测试使用去除内容的独立目录，以便继续检查所有路线；招募测试按真实流程先结束节点拾取再交付。
