# Doro 运行时接入（2026-10-28）

## 交互

- 完成山坡宅邸招募后，在「状态」面板选中 Doro，点击「设为桌面宠物」。仅允许选择已拥有的宠物。
- 当前仍是单桌面主体，可切换咕嘎/Doro；本次不增加多窗口同时展示。选择保存在本地 UI 偏好，重启保留；存档中没有所选宠物时回退第一只，重置存档清空选择。
- 桌面主体只跟随自己的探险队伍。切换展示不派遣、不撤离、不改变任何宠物数值。
- 新解锁宠物不强制抢占桌面。状态头像、配队卡片、已解锁宠物图鉴均使用 Doro 头像；未解锁不暴露头像。
- 吃橘子、秒吞橘子仅为待机演出，不消耗 orange，不触发任务或属性变化。

## 动画

运行时资源只引用 `public/pet-sprites/doro/` 和 `public/pet-portraits/doro.webp`，不引用美术工作目录。

| 状态 | 动画 |
| --- | --- |
| 静止 | standing.png |
| 待机 | blink-plain / orange-offer / orange-blitz，等概率选取非上一段的动作 |
| 睡眠 | sleep-start → sleep-loop → sleep-end → standing |
| 探险 | start-explore → walk → arrive → standing |

各段帧数、帧率、列数及循环标识来自对应 manifest。walk、sleep-loop 循环，其余只播一次。恢复正在行进的存档直接进入 walk，不补播出发。抵达等 walk 回到末帧后切换；快速选择下一路线时先播完抵达，再出发。

咕嘎保留原有动作、权重、行进彩蛋和出发位移修正；Doro 不使用这些不匹配的素材/修正。待机间隔和入睡时间沿用已有逻辑，本次不改玩法数值。

## 尺寸及后台

宠物模板新增 `visualScale`，后台「宠物模板 → 桌面显示尺寸补偿」可编辑，校验范围 0.5～2。

- 咕嘎默认 1。
- Doro 默认 1.0：视觉对比发现原 1.25 倍补偿使主体过大，现取消反向补偿，与咕嘎使用相同比例。旧目录缺字段时也使用 1.0；已保存的显式配置仍以策划后台为准。
- 实际画布 = 用户尺寸设置 × 补偿，再按现有 130～420px 窗口限制裁定；并非放大后裁掉源画布。
- Electron 与浏览器布局使用同一实际尺寸；透明点击检测仍按画布坐标取 alpha。不会把 Doro 的补偿值写进用户全局尺寸偏好。
- 设置预览同步当前宠物静止帧和实际菜单尺寸。
