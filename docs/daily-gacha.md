# 每日扭蛋

记录日期：2026-10-12。backlog 编号 UE-16。

## 机制

- 入口：行动面板第三个 tab「抽奖」，与探险、任务并列。有免费次数时 tab 上有红点，宠物头上的待办灯泡也会亮，点灯泡直达抽奖页（优先级排在待处理远征、可交任务、未分配属性点之后）。
- 每天免费若干次，之后付费。第 n 次付费价格 = 初始价格 × 倍率^(n-1)，是固定金币数，不随解锁地图变化。免费次数与付费计数在本地时间的重置整点清零，错过的天数不累积。
- 一颗蛋只开出一类奖励：金币、经验或道具。先按类别权重抽类别；金币、经验在「预算 × 倍率」上下按浮动比例均匀取值；道具先按稀有度权重抽档位，再在道具池同档条目里按条目权重抽。预算为 0 或道具池为空的类别不参与抽取。
- 经验发给最早加入的宠物（咕嘎），它在外探险时也照样入账。
- 道具优先进仓库；仓库放不下就进抽奖页的「待领取」，玩家腾出空位后手动领取。待领取不随跨日清空。图鉴计数在真正入库时记录。
- 奖励在点按钮时就已入账，开蛋动画只是演出，关闭面板或点击跳过都不影响结果。随机数用存档里的种子，刷新页面不能重抽。

## 预算锚点

用户给定的锚点：一次抽奖约等于「当前解锁的最新地图探索 30 分钟的收益」。

- 每张地图在抽奖配置里有一份预算（金币当量、经验）。玩家已解锁的最新地图决定当天的预算；最新地图没配预算时，沿解锁顺序往前找最近一张配了的。
- 配置台「按地图配置重算」按 `budgetAnchorMinutes` 重新填写所有地图的预算。估算口径同 UE-05：所有完整路线等概率、背包充足，不计随机事件与首次撤离奖励；需要条件或隐藏的路线也计入。实现见 `estimateMapIncome`（`src/domain/gacha.ts`）。
- 2026-10-12 估算：探险者山麓 674 金币当量/小时、22.17 经验/小时（与 UE-05 一致）；克格纳 955 金币当量/小时、24.26 经验/小时。30 分钟预算分别为 337 / 11 与 477 / 12。
- 道具奖励的期望按物品售价计算，不随地图缩放；默认稀有度权重让道具期望约 484，与克格纳的金币预算相当。

## 可配置项（配置台 → 抽奖 → daily）

| 字段 | 默认值 | 说明 |
|---|---|---|
| `resetHour` | 4 | 本地时间重置整点 |
| `dailyFreeDraws` | 1 | 每日免费次数 |
| `paidPrice` | 初始 200 金币、倍率 2 | 付费价格曲线：200 → 400 → 800 → … |
| `prizeWeights` | 金币 40、经验 25、道具 35 | 三类奖励的权重 |
| `currency` | 倍率 1、浮动 0.2 | 金币 = 预算 × 倍率 ±20% |
| `xp` | 倍率 3、浮动 0.2 | 经验预算偏小，开出时放大 3 倍 |
| `itemRarityWeights` | 罕见 600、稀有 370、史诗 25、传说 4、神话 1 | 道具档位权重 |
| `itemPool` | 55 件，权重各 1 | 现有目录中罕见及以上物品，排除任务材料、任务奖励、Tag 道具与次要属性成长道具 |
| `budgetAnchorMinutes` | 30 | 重算预算时的锚点分钟数 |
| `budgets` | 见上 | 每张地图的金币、经验预算 |

游戏只读取 ID 为 `daily` 的那一条。
