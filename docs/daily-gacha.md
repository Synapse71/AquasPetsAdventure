# 每日扭蛋

记录日期：2026-10-12。backlog 编号 UE-16。

## 机制

- 入口：行动面板第三个 tab「扭蛋」，与探险、任务并列。有免费次数时 tab 上有红点，宠物头上的待办灯泡也会亮，点灯泡直达扭蛋页（优先级排在待处理远征、可交任务、未分配属性点之后）。
- 每天免费若干次，之后付费。第 n 次付费价格 = 初始价格 × 倍率^(n-1)，是固定金币数，不随解锁地图变化。免费次数与付费计数在本地时间的重置整点清零，错过的天数不累积。
- 一颗蛋只开出一类奖励：金币、经验或道具。先按类别权重抽类别；金币、经验在「预算 × 倍率」上下按浮动比例均匀取值；道具先按稀有度权重抽档位，再在道具池同档条目里按条目权重抽。预算为 0 或道具池为空的类别不参与抽取。
- 经验发给所有宠物，每只各得一份完整经验（不平分），在外探险的也照样入账。
- 道具优先进仓库；仓库放不下就进扭蛋页的「待领取」，玩家腾出空位后手动领取。待领取不随跨日清空。图鉴计数在真正入库时记录。
- 奖励在点按钮时就已入账，开蛋动画只是演出，关闭面板或点击跳过都不影响结果。随机数用存档里的种子，刷新页面不能重抽。

## 预算锚点

> 本文只描述机制和字段含义，**所有具体数值以配置台（`?config=1` → 抽奖 → daily）为准**，文档不记录、也不同步当前取值。

一次抽奖的金币、经验基准锚定为「当前解锁的最新地图探索若干分钟的收益」，分钟数由配置项 `budgetAnchorMinutes` 决定。

- 每张地图在抽奖配置里有一份预算（金币当量、经验）。玩家已解锁的最新地图决定当天的预算；最新地图没配预算时，沿解锁顺序往前找最近一张配了的。
- 配置台「按地图配置重算」按 `budgetAnchorMinutes` 重新填写所有地图的预算。估算口径同 UE-05：所有完整路线等概率、背包充足，不计随机事件与首次撤离奖励；需要条件或隐藏的路线也计入。实现见 `estimateMapIncome`（`src/domain/gacha.ts`）。改了地图配置（节点、路线时长、掉落、`nodeXp`）后需要重新点一次，预算不会自动更新。
- 道具奖励的期望按物品售价计算，不随地图缩放；配置台预算表会按地图列出单抽期望，供对照金币预算调整道具权重。

## 可配置项（配置台 → 抽奖 → daily）

| 字段 | 含义 |
|---|---|
| `resetHour` | 每日重置的本地整点（0～23），跨过它免费次数与付费计数清零 |
| `dailyFreeDraws` | 每天的免费次数 |
| `paidPrice.base` | 当天第 1 次付费的价格（金币），固定值，不随地图变化 |
| `paidPrice.growth` | 付费价格倍率：第 n 次 = `base × growth^(n-1)`，不小于 1 |
| `prizeWeights` | 金币、经验、道具三类奖励的抽取权重；基数为 0 或道具池为空的类别不参与抽取 |
| `currency.multiplier` / `currency.spread` | 开出金币 = 最新地图金币预算 × 倍率，再上下均匀浮动 spread 比例 |
| `xp.multiplier` / `xp.spread` | 开出经验 = 最新地图经验预算 × 倍率，再上下均匀浮动 spread 比例；每只宠物各得一份 |
| `itemRarityWeights` | 道具先按这里的权重抽稀有度档位；道具池里没有条目的档位不会被抽到 |
| `itemPool` | 道具池：物品 ID + 权重，同档内按权重抽。初始内容取现有目录中罕见及以上物品，排除任务材料、任务奖励、Tag 道具与次要属性成长道具 |
| `budgetAnchorMinutes` | 「按地图配置重算」使用的锚点分钟数 |
| `budgets` | 每张地图的金币、经验预算，可重算生成，也可手填 |

取整规则：金币、经验与付费价格都只在最后一步四舍五入，并且最少为 1；中间计算不取整。

游戏只读取 ID 为 `daily` 的那一条。

## 现状与后续

- 第一阶段（本次）：机制、配置台表单、行动面板扭蛋页、纯 CSS 占位开蛋动画（转把手 → 蛋落下 → 摇晃开壳；蛋壳色和光晕按稀有度分档，金币蛋、经验蛋各有固定色）。
- 第二阶段（2026-10-14 完成）：正式美术。
  - 扭蛋机静态图：游园招牌款，招牌上是游戏 logo（海蓝色「A」），作为所有开蛋视频的首帧，也是扭蛋页的待机图。

  - 光效不冲天：只在扭蛋周围一个圆形范围内。
  - 各档只换颜色：除了扭蛋、光效、星星的颜色，开蛋动画完全一致。只生成稀有档一条母版，其余档位由构建脚本从母版逐帧换色（目标色相取自稀有度色板），扭蛋机本身不动。
  - 管线：`assets/ui-prototype/gacha/opening-v1/gen_videos.py` 出稀有档原片 → 在 `rare/chosen.txt` 写选定的 take → `tools/build-gacha-opening.py` 换色出其余档、转码、四边羽化、逐帧验边、核对首帧与待机图。
  - 抠图验收：`opening-v1/matte_preview.py <档>` 把白底视频抠出来铺在品红底上，检查换非白背景时能不能用。只是预览，游戏里仍是白底视频铺在白底舞台上。
