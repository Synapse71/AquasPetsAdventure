# 钓鱼玩法设计共识

> 确认日期：2026-10-21。
> 状态：玩法与交互已确认，待实现。本文记录访谈最终结论，不代表代码已具备这些能力。
> 面向系统、UE、美术与后续开发 agent。钓鱼专属规则以本文为准，库存、探险等通用规则继续沿用项目现有机制。

## 1. 定位与本期范围

钓鱼是玩家忙碌时可以放心放着的休闲挂机活动，提供渔获、宠物成长和图鉴收集目标。玩家主动安排，不会因宠物空闲而自动开始。不需要玩家及时点击咬钩或收竿，每轮必定获得一件渔获。

- 同一宠物不能同时钓鱼和探险；多只空闲宠物可以同时钓鱼，各自独立计时、装备和积累收获。
- 本期不设置钓点选择，直接在桌面表现钓鱼；可钓获范围由鱼竿配置决定。
- 通过引导任务解锁钓鱼，条件由策划配置；宠物默认配备基础鱼竿和基础鱼篓。
- 不强制消耗鱼饵。本期不实现鱼饵消耗与补充流程，后续可增加提供钓鱼增益的鱼饵物品。
- 本期共用钓鱼动画，不实现不同装备的桌面外观差异，以玩法实现为优先。

## 2. 活动生命周期与计时

```text
未钓鱼 → 主动开始 → 钓鱼中
钓鱼中 → 一轮完成：生成一件渔获 → 未满则开始下一轮
钓鱼中 → 鱼篓满 → 暂停并提示 → 领取腾出空间 → 继续钓鱼
钓鱼中／鱼篓满 → 整理收获 → 确认领取 → 继续钓鱼或保持满篓暂停
钓鱼中／鱼篓满 → 整理收获 → 确认收竿 → 未钓鱼
整理收获 → 取消 → 恢复原有收获与活动状态
```

### 2.1 在线与暂停

- 游戏运行期间，最小化、后台运行、只显示桌宠或隐藏宠物均继续钓鱼。
- 仅锁屏且电脑未休眠时继续；电脑休眠时暂停，唤醒后接着原进度。
- 退出游戏不积累收益；保存当前轮次进度，下次启动后继续，不补算关闭期间时间。
- 鱼篓满时暂停，不在暂停期间积攒未来轮次；领取腾出空间后自动继续。
- 整理期间暂停对应宠物的钓鱼，其他宠物不受影响；取消整理恢复原状态，不扣收获或重置当前轮次。
- 收竿结算已完成轮次，未完成轮次不产生奖励，结束后不保留该轮进度。
- 此计时规则与探险的离线现实时间规则不同，不能直接复用探险到达时间补算逻辑。

### 2.2 轮次耗时与结果

- 鱼竿配置基础耗时区间，鱼竿品质／装备配置与感知等修正影响该区间。
- 每轮开始时，根据当时有效属性计算区间，并随机确定本轮实际耗时。
- 本轮属性效果在轮次开始时锁定。升级、加点、伤势恢复等变化从下一轮生效；暂停恢复不得重新抽取耗时。
- 每轮必定产出一件，可能是鱼或普通物品，没有空竿。
- 钓获时确定并保存物品身份；鱼同时确定并保存实际长度与实际售价。领取、取消、退出重启都不能重抽。
- 不显示每轮耗时、耗时区间、倒计时或轮次进度条。

## 3. 宠物属性与伤势

沿用现有三项主属性命名，访谈中的“力量”对应项目中的“体能”。

| 属性 | 钓鱼作用 |
|---|---|
| 体能 | 修正鱼的实际长度；不为普通物品生成长度 |
| 感知 | 修正钓获耗时区间 |
| 技巧 | 修正可钓获范围内的高稀有度概率，不能突破鱼竿稀有度上限 |

正常与受伤宠物都可钓鱼，使用伤势影响后的有效主属性。钓鱼属于基地活动，期间伤势照常恢复；失能宠物不能开始钓鱼。钓鱼本身不造成伤势，且与探险互斥，正常玩法不存在钓鱼途中因钓鱼变成失能的分支，不为此增加玩法或弹窗。

## 4. 鱼竿与鱼篓

- 两类装备均接入物品系统，具备物品 ID、品质、图标、说明及通用出售配置。
- 每只宠物有独立鱼竿、鱼篓装备位；一件实物只能装备给一只宠物。
- 装备从仓库移入装备位；更换后的旧装备回到仓库，遵守容量检查与现有物品保护规则。
- 正在钓鱼时不允许更换装备，包括鱼篓满、正在整理等尚未结束活动的状态；先完成收竿才能更换。
- 每只宠物在获得时赠送一次基础鱼竿和鱼篓。卸下、出售后不自动补发。
- 开始钓鱼必须同时装备鱼竿和鱼篓；缺少时明确提示，并提供商店补购入口。
- 新装备复用任务奖励、商店、探险掉落等渠道；具体投放内容由策划配置。

### 4.1 鱼竿能力

鱼竿决定具体渔获池和基础耗时区间，鱼竿品质限制渔获的最高稀有度。绿色“专业钓竿”只能钓到绿色及以下渔获；未来紫色鱼竿可开放更高稀有度。上限同时约束鱼和普通物品，技巧不能让绿色鱼竿钓出蓝色渔获。

渔获池支持鱼类和普通物品混合。鱼竿不会自动开放所有低于其品质的物品，具体候选仍由其池子决定。稀有度权重、池内权重及属性修正全部配表。

### 4.2 鱼篓容量

鱼篓按件数计容量，一条鱼或一件普通物品均占一个位置；普通物品在鱼篓内不因可堆叠而少占容量。大鱼不会额外占容量。容量在装备界面的物品 tooltips 展示，活动界面可显示当前鱼篓件数。

## 5. 鱼类数据、价格与库存

每个鱼种配置标准长度、标准售价、固定单条重量、固定钓鱼经验，以及长度生成所需参数。每条实际钓获的鱼是独立实例，记录鱼种、实际长度、实际售价和必要的实例身份信息。

```text
实际售价 = 四舍五入（标准售价 × 实际长度 ÷ 标准长度）
```

- 每条鱼单独占库存一格，不堆叠；长度不改变负重，同鱼种使用固定单条重量。
- 长度影响售价和图鉴纪录，不影响同鱼种的经验。
- 普通物品没有长度属性，售价、重量、入库堆叠均沿用原有规则。
- 本期鱼类仅由钓鱼产生。策划后台需拦截把鱼类放入任务奖励、商店商品、探险掉落等其他生成渠道，避免产生无长度的鱼。
- 鱼类可出售、收藏、提交任务，也可以像任何库存物品一样带入探险初始背包。不得特殊禁止携带。
- 探险携带、整理、入库、出售、丢弃、溃败丢失等操作必须保留或正确移除该鱼实例及长度，不能退化为同鱼种数量。
- 直接接入库存已有锁定功能和保护交互，不另做鱼类专属锁定玩法。实例化存储需确保通用锁定能正确保护所选物品。

## 6. 收获整理与经验

提供两个操作：

| 操作 | 处理范围 | 确认后 |
|---|---|---|
| 领取收获 | 可只处理部分渔获，其余留在鱼篓 | 有空间则继续钓鱼，满篓则保持暂停 |
| 收竿 | 必须处理全部渔获 | 结束钓鱼，清空鱼篓，放弃未完成轮次 |

整理沿用探险撤离的入库、出售、丢弃交互；允许组合处理。仓库不足时由玩家重新分配，不能静默删除或溢出。确认应一次性校验和提交，失败保留原收获；取消恢复原活动状态。收竿整理无收获时也应明确提示未完成轮次不会产生奖励。

- 每个鱼种的钓鱼经验独立配置，同种鱼固定，不随长度或稀有度统一公式变化。
- 普通物品不给钓鱼经验。
- 整理确认后，入库和出售的鱼发放经验，丢弃的不发放；部分领取只结算实际处理的部分。
- 经验属于钓获该鱼的宠物。多宠统一整理仍按来源分别结算，不共享或重复发放。
- 已领取的鱼以后出售、提交任务或探险带回不再获得钓鱼经验。探险带回沿用初始携带物品不算新战利品经验的规则。

## 7. 探险派遣衔接

1. 配队界面明确标记正在钓鱼的宠物（包括满篓暂停的宠物）。
2. 选中它们本身不结束活动；点击“下一步”时弹出收竿提示。
3. 弹窗展示此时收竿可结算的具体渔获和经验；按入库、出售、丢弃的选择展示最终收益。
4. 若选中多只钓鱼宠物，使用一个弹窗，按宠物分组，统一整理全部收获，一次确认全部收竿。
5. 取消则全部保持原钓鱼状态，并留在配队界面；确认并成功结算后才进入下一步。
6. 不能只成功收竿其中一部分就报错退出；需整体校验库存容量和操作有效性。

触发时点是配队的“下一步”，不是最终出发，也不是打开行动面板时。已确认收竿后即便后来取消探险，也不会擅自重新开始钓鱼。

## 8. 任务、图鉴与解锁

- 引导任务解锁整个钓鱼功能，任务前置与达成条件可配置；不新增第五个以外的桌宠主菜单入口。
- 任务支持指定鱼种、数量以及可选长度条件。具体条件通过表单配置。
- 提交时可选择符合条件的具体鱼，默认优先较短的符合条件个体，并遵守现有锁定规则，避免误交收藏鱼。
- 鱼类接入全局物品图鉴：首次钓获解锁，记录累计钓获数量与该鱼种历史最大长度。
- 图鉴在钓获时登记，不等领取；后来出售或丢弃不抹除纪录。领取不得再次增加累计数量。
- 沿用未解锁剪影、“？？？”以及已解锁完整信息的展示规则。
- 普通物品的钓获也接入既有获得记录，注意鱼篓到仓库转移不能重复登记。

## 9. UE 与美术表现

### 9.1 入口与信息边界

- 入口放在现有“行动”面板，与“探险”并列。
- 面板统一展示各宠物钓鱼状态，点击某只可查看其装备与收获，进行领取或收竿。
- 通过桌宠钓鱼状态进入对应收获／装备界面。
- 不提供鱼竿渔获池预览，包括已解锁名称和未解锁剪影列表也不展示；具体内容由实际钓获发现。
- 不展示每轮耗时、耗时区间、倒计时、轮次进度条，不能照搬探险行进进度 UI。
- 鱼篓容量在装备 tooltips 展示；鱼篓内容可查看鱼的长度、售价和普通物品信息。

### 9.2 动画与通知

- 钓鱼中：桌面宠物持续播放专属钓鱼动画，与探险中播放行进动画的状态驱动方式相似。
- 鱼篓满：停止钓鱼表现，切换到等待领取状态，并通过灯泡持续提示。
- 领取腾出空间：恢复钓鱼动画；收竿：回到普通待机。
- 钓到新品种或刷新长度纪录：显示短暂、非阻塞气泡，不暂停活动、不要求点击。普通钓获只更新收获并提供相应表现，不持续催促。
- 多宠独立表现自己的活动与满篓状态，不能一只满篓让其他宠物停下。
- 沿用既有桌宠面板布局和提示风格，不为钓鱼长期展开大型面板。

### 9.3 本期素材决策

用户希望未来看到不同钓鱼装备外观，但本期优先玩法。当前“生成视频再切连续帧”的动画管线不适合低成本组合大量鱼竿、鱼篓外观，因此本期所有装备共用钓鱼动画，差异通过物品图标、tooltips 和实际效果体现。

后续若制作装备外观差异，可评估宠物与装备分层的表现方案；这只是扩展方向，本期不改动画管线，不要求逐装备制作动画组合。本期需要支持钓鱼持续动作、钓获反馈、满篓等待及回待机的状态表达，具体素材清单与资产接口在实现时对接美术文档，不把本文当成已有素材清单。

## 10. 配置台与实现约束

新增数值必须进入 `src/config/` 表单与配表数据，不能写死在引擎或拿数值方案向用户反复征询。实现时按现有进程锚点选默认值，并在交付记录中列出实际默认值。本次仅落机制文档，不杜撰已经确认的数值。

| 配置对象 | 需要提供的配置项 |
|---|---|
| 鱼种物品 | 稀有度、标准长度、标准售价、固定重量、固定经验、长度生成区间／分布参数、图标与描述 |
| 鱼竿物品 | 品质、混合渔获池引用、基础耗时区间、通用出售属性 |
| 渔获池 | 鱼类／普通物品引用、稀有度及池内抽取权重 |
| 鱼篓物品 | 件数容量、品质、通用出售属性 |
| 属性修正 | 体能对长度、感知对耗时区间、技巧对稀有度概率的参数及边界 |
| 宠物初始装备 | 默认基础鱼竿、基础鱼篓引用；老存档补齐时防止重复赠送 |
| 任务 | 钓鱼解锁奖励／条件、鱼种提交需求与可选长度条件 |
| 投放 | 任务、商店、探险中钓鱼装备的投放配置 |

校验至少覆盖有效引用、正标准长度、合法长度与时间区间、合法容量和经验、可抽取池非空、鱼竿品质上限与池子的兼容性、禁止其他渠道生成鱼。候选池中超过鱼竿上限的物品不能在运行时漏出。

现有库存以物品 ID 计数量，不能直接表达同种鱼的不同长度。实现必须补齐实例物品在仓库、初始背包、探险结算、任务提交、锁定、存档导入导出中的完整流转，同时保持普通物品的堆叠行为。

计时需区分后台运行、退出、休眠和整理暂停；保存轮次耗时、已用进度及本轮属性效果，防止重启重抽和错误补发离线收益。多宠统一整理与派遣收竿应采用原子结算，不能重复领取。

## 11. 验收要点

- 未解锁不能开始；默认装备只发一次；缺装备、失能、正在探险均不能开始钓鱼。
- 多宠可同时钓鱼，装备、轮次和鱼篓互不混淆；活动期间禁止换装备。
- 后台运行继续，退出／休眠暂停，恢复保留进度；满篓不继续生产，领取后恢复。
- 每轮一件，技巧不突破鱼竿上限，长度只属于鱼；本轮属性效果固定。
- 部分领取、全部收竿、取消、仓库不足、锁定物品以及多宠派遣确认均保持数据一致。
- 鱼实例独立占格，价格按长度比例，固定鱼种重量；携带探险后长度不丢失，溃败正确丢失。
- 经验只在整理确认时按鱼种发给来源宠物，普通物品与丢弃物不给经验，后续转移不重复结算。
- 任务支持选择符合长度条件的鱼；图鉴钓获即登记，出售丢弃后纪录保留。
- 无渔获池预览、无时间与进度信息；钓鱼动画、满篓等待灯泡、新鱼／纪录气泡符合本文。
- 本期无离线钓鱼收益、钓点、强制鱼饵、装备差异动画。

开发验证默认使用类型检查、单测与构建；Electron 冒烟测试仅在用户明确要求时运行。本次文档完成不代表 UE-08 玩法实现完成。
